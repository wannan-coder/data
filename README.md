# 《代码随想录》智能客服系统

## 简介

这是一个为《代码随想录》算法学习资料打造的智能客服系统，能够帮助用户：
- 🔍 快速查找相关算法学习资料
- 💡 获取学习建议和路径指导
- 📚 了解资料库中的所有学习资源

## 功能特点

### 1. 智能主题识别
系统能够识别以下算法主题：
- 数组 (Array)
- 链表 (Linked List)
- 哈希表 (Hash Table)
- 字符串 (String)
- 双指针 (Two Pointers)
- 栈与队列 (Stack & Queue)
- 二叉树 (Binary Tree)
- 回溯算法 (Backtracking)
- 贪心算法 (Greedy)
- 动态规划 (Dynamic Programming)
- 单调栈 (Monotonic Stack)

### 2. 常见问题解答
系统内置了常见问题的答案：
- 如何开始学习？
- 推荐的学习顺序是什么？
- 资料的难度如何？
- 如何提问？

### 3. 资料导航
可以查看所有可用的PDF学习资料，并根据需求获取推荐。

## 使用方法

### 前置要求
- Python 3.6 或更高版本

### 运行系统

1. 确保您在包含PDF资料的目录中
2. 运行客服系统：

```bash
python smart_customer_service.py
```

或者直接执行：

```bash
python3 smart_customer_service.py
```

### 使用示例

#### 示例 1：查询特定主题的资料
```
您: 我想学习动态规划
客服: 根据您的需求，我找到了以下相关资料：

📚 10.《代码随想录》动态规划（V3.0）

这些资料涵盖了：动态规划
```

#### 示例 2：询问学习建议
```
您: 如何开始学习？
客服: 您可以从数组和链表开始学习，这是算法学习的基础。推荐先看《代码随想录》数组和链表的PDF。
```

#### 示例 3：查看所有资料
```
您: 有哪些资料？
客服: 我们有以下学习资料：

1. 0.《代码随想录》PDF说明
2. 1.《代码随想录》数组（V3.0）
3. 2.《代码随想录》链表（V3.0）
...
```

#### 示例 4：查询学习顺序
```
您: 推荐的学习顺序
客服: 建议学习顺序：1.数组 → 2.链表 → 3.哈希表 → 4.字符串 → 5.双指针 → 6.栈与队列 → 7.二叉树 → 8.回溯算法 → 9.贪心算法 → 10.动态规划 → 11.单调栈
```

### 退出系统
输入以下任一命令退出：
- `exit`
- `quit`
- `退出`
- `再见`

或按 `Ctrl+C`

## 技术实现

### 系统架构
- **编程语言**: Python 3
- **设计模式**: 面向对象设计
- **核心功能**:
  - 文件扫描与索引
  - 关键词匹配
  - 主题识别
  - 智能问答

### 主要类和方法

#### SmartCustomerService 类
- `__init__()`: 初始化系统，加载资料和知识库
- `process_query(user_input)`: 处理用户查询
- `run()`: 运行客服系统主循环

## 扩展和定制

您可以根据需要扩展系统功能：

1. **添加新主题**: 在 `topic_keywords` 字典中添加新的主题和关键词
2. **扩展FAQ**: 在 `faq` 字典中添加更多常见问题和答案
3. **改进匹配算法**: 修改 `_match_topic()` 方法以提高匹配准确度
